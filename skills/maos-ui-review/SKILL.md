---
name: maos-ui-review
description: Review MAOS or connected-system UI for functional, visual, responsive, accessibility, permission, and human-work correctness.
---

Review functional correctness, information hierarchy, human-work efficiency, visual consistency, responsive behavior, WCAG 2.2 AA, permission visibility, AI activity transparency, structured status, and error/empty/loading/blocked/approval states.

For CRM prioritize minimum data entry, natural-language capture, no duplicate reporting, Today/My Tasks/Customers/Listings/Calendar/Documents/Reports, and strict separation of employee work data from private personal data.

Report: Issue / Severity / Screen or component / Evidence / Recommended correction.
